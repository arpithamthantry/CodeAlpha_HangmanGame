# CodeAlpha Hangman Game

A fun and interactive Hangman word-guessing game developed in Python as part of the CodeAlpha Python Programming Internship.

## Features

- Multiple difficulty levels
- Random word selection
- Limited attempts
- Limited hints
- ASCII Hangman visuals
- Input validation
- Duplicate-guess protection
- Score tracking
- Replay option
- Session statistics

## Technologies Used

- Python 3
- Random module
- Standard Python libraries

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run:

    python hangman.py

## How to Play

1. Choose a difficulty level.
2. A hidden word will be selected.
3. Guess letters one at a time.
4. Avoid incorrect guesses and complete the word before you run out of attempts.
5. Use your available hints wisely.
6. Try to achieve the highest score!

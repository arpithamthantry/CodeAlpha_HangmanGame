CODEALPHA HANGMAN GAME 
A fun and interactive Hangman word-guessing game developed in Python as part of the CodeAlpha Python Programming Internship.

FEATURES
Multiple difficulty levels
Random word selection
Limited attempts
Limited hints
ASCII Hangman visuals
Input validation
Duplicate-guess protection
Score tracking
Replay option
Session statistics

TECHNOLOGIES USED
Python 3
Random module
Standard Python libraries

HOW TO RUN
1. Make sure Python 3 is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run:
```bash
python hangman.py

HOW TO PLAY
Choose a difficulty level.
A hidden word will be selected.
Guess letters one at a time.
Avoid incorrect guesses and complete the word before you run out of attempts.
Use your available hints wisely.
Try to achieve the highest score!
